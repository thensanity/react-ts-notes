Two-minute project script

Say this

React 19, TypeScript, Vite. Search city and optional country. Geocode, then current weather by lat/lon. Loading and error states. History is 20 unique places in localStorage. Light and dark theme. Vitest on the mapper and main flow. The Vite API key is not production-safe; in production I would proxy it. Happy to go deeper if you want — otherwise I can talk about MAF.

Then stop

Do not list every file. One follow-up is enough: geocoding versus a single q= call, abort on double search, or the API key. After that, hand the hour back to them.
